# QRCSatellite

**ESPHome WiFi QR Display Client for ATOM S3**

Display WiFi QR codes generated by QRCService on your ATOM S3 device.

## Features

- 📱 Displays QR codes from QRCService
- 🔄 Manages multiple WiFi networks
- 🎮 Button control for network selection
- 📡 Automatic QR code download
- 🖥️ Clean UI on 128x128 LCD

## Hardware Requirements

- **M5Stack ATOM S3**
- ST7789V 128x128 LCD display
- Button on GPIO41

## Installation

### 1. Prerequisites

- ESPHome installed (≥ 2026.1.0)
- QRCService installed in Home Assistant
- ATOM S3 device

### 2. Configuration

1. Copy `secrets.yaml.example` to `secrets.yaml`
2. Edit `secrets.yaml` with your credentials:
   ```yaml
   wifi_ssid: "YourNetwork"
   wifi_password: "YourPassword"
   ha_url: "http://homeassistant.local:8123"
   api_key: "your_32_char_key"
   ```

3. Generate API encryption key:
   ```bash
   esphome wizard qrcsatellite.yaml
   # Copy the generated API key to secrets.yaml
   ```

### 3. Compile and Upload

```bash
# Compile
esphome compile qrcsatellite.yaml

# Upload via USB
esphome upload qrcsatellite.yaml

# Or upload via WiFi (after first flash)
esphome upload qrcsatellite.yaml --device qrcsatellite.local
```

## Usage

### Adding Networks

Via Home Assistant:
```yaml
service: esphome.qrcsatellite_add_network
data:
  ssid: "GuestWiFi"
  password: "GuestPassword123"
```

### Button Controls

- **Short press**: Cycle through saved networks
- **Long press (1+ sec)**: Request and display QR code

### Display Modes

**Main Menu:**
- Shows current network selection
- Network counter (e.g., "Network 1/3")
- Instructions

**QR Display:**
- Network name
- QR code image (downloaded from QRCService)
- Scan instructions

## Integration with QRCService

QRCSatellite automatically connects to QRCService when:

1. You long-press the button
2. QRCSatellite calls `qrcservice.generate_wifi_qr`
3. QRCService generates QR and fires event
4. QRCSatellite downloads image via HTTP
5. Display shows QR code

## Home Assistant Services

### `esphome.qrcsatellite_add_network`
Add a WiFi network to the device.

```yaml
service: esphome.qrcsatellite_add_network
data:
  ssid: "NetworkName"
  password: "Password123"
```

### `esphome.qrcsatellite_clear_networks`
Clear all saved networks.

```yaml
service: esphome.qrcsatellite_clear_networks
```

### `esphome.qrcsatellite_request_qr`
Manually request QR generation for current network.

```yaml
service: esphome.qrcsatellite_request_qr
```

## Sensors

- **`text_sensor.qrcsatellite_current_network`**: Currently selected network
- **`sensor.qrcsatellite_network_count`**: Number of saved networks

## Troubleshooting

### Display is black
- Check backlight connection (GPIO16)
- Verify SPI pins (CLK=17, MOSI=21)
- Check display pins (CS=15, DC=33, RST=34)

### Button not working
- Verify GPIO41 connection
- Check pullup resistor enabled
- Review logs for button events

### QR not downloading
- Verify QRCService is running
- Check `ha_url` in secrets.yaml
- Ensure `/config/www/qrcodes/` exists
- Review ESPHome logs for HTTP errors

### No networks showing
- Add networks via Home Assistant
- Check API connection
- Review logs for service calls

## Architecture

```
QRCSatellite (ATOM S3)
  ↓ Long press button
  ↓ Call HA service
QRCService (Home Assistant)
  ↓ Generate QR image
  ↓ Save to /config/www/qrcodes/
  ↓ Fire event
QRCSatellite
  ↓ Download image via HTTP
  ↓ Display QR on LCD
```
